二、入选更新：完整七维技术分析

1. Google / DeepMind：Gemini 4 Hydrogen——高频 Agent 与长输出的新工程选项

① 官方信息、日期、Model ID、发布状态与直接来源。 官方原文标题 Introducing Gemini 4 Hydrogen，2026-11-12 发布、11-13 更新；DeepMind Model Card标明发布日期 11 月 12 日。正式模型 gemini-4-hydrogen，Google Cloud 模型目录归入一般可用模型；可通过 Gemini API、AI Studio、Google Cloud 企业 Agent 平台等渠道访问，实际免费额度、地区、付费资格及 Antigravity 席位按产品和账户核实。不是 Gemini CLI 版本更新，也不是在 GitHub 开放权重。

② 核心变化与技术机制。 Google 将它定位为 Carbon/Argon 的高效执行搭档：Carbon 做复杂长程判断，Hydrogen 做高频编写、测试与验证；Antigravity Orchestrator 可在一次任务中协调模型，但 Orchestrator 不是独立的开放基础模型。输入支持文本、图像、音频、视频，输出为文本。Context 为输入+思考+工具调用+输出共享的 1,048,576 Token 总预算，不是输入 1M 后还能额外输出 1M。单次前台段最大约 65,536 输出 Token；在 Interactions API 或 GenerateContent v1beta1 通过 continuation/后台 long decode 才能在剩余上下文中继续扩展。Thinking 支持 LOW、MEDIUM、HIGH（默认）、XHIGH；传旧式 thinking_budget 或 MINIMAL 会报 400；自定义 temperature/top_p/top_k 可能被忽略。支持 JSON Schema、function calling、code execution 和部分搜索工具，但 不支持 Gemini Live API、不支持 RAG Engine，也不提供可下载模型权重。只支持隐式 Context Cache，不能把旧模型的显式缓存参数直接迁移。正式规格。

③ 为什么有价值及证据边界。 这是对“同一个最强模型包办所有 Agent 步骤”的替代：复杂规划使用更强模型，重复代码编辑、检索提取、回归测试、结果验证使用高效模型，可由 Gateway 按任务分层路由。Google 官方称 Antigravity Orchestrator 在指定 Terminal-Bench 4.0 设置下配额少 24%、速度快 19%；这是厂商报告的特定评测，不是我们自己的生产 P95、费用或正确率证明。Google 博客引用的 Artificial Analysis 指数也需按测试时间和版本核对，不得跨版本直接排序。此次没有执行独立实测。

④ 产品与业务场景。 适用于企业代码修复与批量重构、知识工作 Agent、公开资料分析、复杂 PDF/Office 文档理解、并行 Worker/Verifier、自动化报告及低延迟用户请求。输入 Office/OpenDocument 支持包括 DOCX/PPTX/XLSX（以具体 API 和 MIME 类型为准）。不适合强制使用 RAG Engine 或必须原生实时音视频 Live 的项目，应选择相应可用模型或自有 RAG 服务。

⑤ 对软件开发、Java/Spring Boot、Nacos、跨语言 AI Gateway 的帮助。 将模型选型从“单一 provider+model”改成“planner / executor / verifier 分工”，并在能力注册表记录 model_id、API surface、thinking_level、max_segment_output、long_decode、context_total、modalities、tools、region、tier、price。在 Spring Boot 的 Gateway Adapter 中为 Google Gen AI SDK/REST 单独实现 continuation_token 状态持久化、幂等续接、SSE 断流处理与响应预算统计。Nacos 只存版本/路由配置，API Key 由 Secret Manager 管理。采用 Agent 执行状态机保存 run_id、step_id、continuation_token、attempt 与 idempotency_key；旧的“max_output_tokens=1M 一次性输出”假设必须纠正。

⑥ 实践、升级、兼容/安全/成本、验收。 先用 Google AI Studio 或官方 Google Cloud 开发指南验证账号可用，再做 4 档 Thinking 的同任务 A/B。Windows PowerShell 7 的只读检查命令如下，不会泄露密钥：

# 在测试机运行；API Key 仅通过环境/凭据系统安全注入
if (-not $env:GEMINI_API_KEY) { throw '请先设置 GEMINI_API_KEY' }
$headers = @{ 'x-goog-api-key' = $env:GEMINI_API_KEY }
$body = @{
  contents = @(@{ parts = @(@{ text = '请列出一个 Java API Gateway 的三项幂等风险' }) })
  generationConfig = @{
    thinkingConfig = @{ thinkingLevel = 'HIGH' }
    maxOutputTokens = 2048
  }
} | ConvertTo-Json -Depth 12
Invoke-RestMethod -Method Post `
  -Uri 'https://generativelanguage.googleapis.com/v1beta/models/gemini-4-hydrogen:generateContent' `
  -Headers $headers -ContentType 'application/json; charset=utf-8' `
  -Body ([Text.Encoding]::UTF8.GetBytes($body)) -TimeoutSec 90

这是待本地执行的示例，本日报没有调用用户的计费 API。请在正式运行前核对所用 Gemini API surface 的模型/字段支持；Google Enterprise 平台的 ADC/project/region 鉴权与 Gemini Developer API Key 不可混为一套。官方博客列出标准 Token 价格 输入 $1.50 / 百万、输出 $7.50 / 百万（包含 Thinking 输出开销的口径须看实际账单）；不把这价格套用到第三方 Base URL、搜索接地工具或企业服务层。测试矩阵包括 HIGH/XHIGH Token 用量、Schema 合规、工具调用、65K 段限制、长输出恢复、缓存、429/5xx、P95 与预算熔断。验收： 20 个固定任务结果可复现、错误不重复写入、相同输入下观察到可解释的费用/延迟差异、续接后结果无缺段、个人数据使用及存储符合账户条款。

⑦ 决策和优先级。 必看（历史补录），建议先在测试环境试用而非全量迁移。 如现有 3.8 Flash/Argon 表现稳定，先做任务级路由 A/B；不盲目切换 CLI 或把官方性能宣传当真实业务 SLA。生产升级成本集中于 Thinking 字段、统一 Token 预算、长输出续接、成本核算与权限治理。

2. 百度 / 文心 / 千帆：ERNIE 5.5 Flash Preview 与三模型上架——国内企业 AI 编程和长上下文的补录

① 官方信息、准确日期、版本及来源。 百度文心官网在 2026-11-11 发布《ERNIE 5.5 Flash Preview 发布》，是此前 Flash Base 的首个后训练版本。ERNIE-5.5-Flash-Preview 是预览版，不得写成 GA。百度声明其 API 已在千帆上架，模型权重计划在 11 月 25 日前开源；截至本次核查不能把未来计划当作已经下载到权重。百度智能云另有 三模型产品页，列出 ERNIE-Light-DT-1.0 与 ERNIE-Wizshot-ME；该营销页没有独立可核实的每个模型最初上线日，列为本期发现的历史相关信息，而非“今日新发布”。

② 核心变化、原理和知识点。 ERNIE-5.5-Flash-Preview 官方称 280B 总参数/14B 每 Token 激活的 MoE、1M 上下文、默认输出 64K、200+ Token/s，针对 Agentic Coding、知识工作和 3D/视频创作训练。它是文本→文本模型，即使能通过工具生成视频，也不能将其描述为“原生视频输出模型”。配套 ERNIE-Light-DT-1.0 使用 BSA 稀疏注意力与历史压缩思想，最大输出 128K、可开关思考；ERNIE-Wizshot-ME 是异步图片+文本+音频驱动的微表情视频生成模型，视频 1080p、4–15 秒。BSA、MoE 和 KV Cache 优化是降低推理开销的机制方向，不能从架构直接推断端到端 Token 价格或线上 P95。官方规格。

③ 为什么有价值和验证边界。 百度为国内千帆用户提供新的编码/Agent/长文档能力及国产云服务选择。多模型路线允许将复杂模型用于编码/规划、Light-DT 用于成本敏感长文本、Wizshot-ME 用于内容生成。但“200+ Token/s”“第一梯队”等是厂商宣称的测试表现；本期无第三方一致硬件、任务、上下文、并发口径验证。不能由此得出超过 Gemini、Claude 或 GPT 的生产质量结论。

④ 适用业务场景。 中文客服、企业知识库、复杂办公文档、长期 Agent 项目、Java/TypeScript 编码、创作工作流、图片驱动短视频。需特别区分面向消费者的文心产品与企业可调用的千帆模型接口；云资源、地域、实名认证、账户额度、内容审核、配额都必须在实际企业账户确认。

⑤ 对 Java/Spring Boot、AI Gateway、Nacos 与分布式架构的帮助。 千帆提供 POST https://qianfan.baidubce.com/v2/chat/completions，同时有 Responses API；接口形态相近并不等于 Thinking/Tool Call/缓存/图片协议一致。建议 BaiduAdapter 实现 request_schema 和 provider_model_id 双重校验，基于租户绑定合规地域、凭据、限额。具体 model 入参以千帆模型列表/控制台实际 API 名为准，不能仅根据营销标题自行拼写。长文档与 1M Context 也要评估 KV Cache、计费、P95 和 Compaction；异步视频则需任务 ID、轮询、重试去重与完成态回读。Nacos 负责非敏感路由配置，业务运行状态落到持久存储。提供千帆文本生成参数文档。

⑥ 实践代码、价格、兼容与验收。 Windows PowerShell 7 用安全环境变量测试（MODEL_ID 要在企业控制台确认，不擅自将营销型号视为合法 API ID）：

if (-not $env:QIANFAN_API_KEY) { throw '缺少 QIANFAN_API_KEY' }
if (-not $env:QIANFAN_MODEL_ID) { throw '请从千帆模型列表确认 QIANFAN_MODEL_ID' }
$headers = @{ Authorization = "Bearer $env:QIANFAN_API_KEY" }
$body = @{
  model = $env:QIANFAN_MODEL_ID
  messages = @(@{ role='user'; content='请为 Java 微服务设计三个幂等测试用例' })
  stream = $false
} | ConvertTo-Json -Depth 8
Invoke-RestMethod -Uri 'https://qianfan.baidubce.com/v2/chat/completions' `
  -Method Post -Headers $headers -ContentType 'application/json; charset=utf-8' `
  -Body ([Text.Encoding]::UTF8.GetBytes($body)) -TimeoutSec 90

SDK/Schema 风险：官方千帆参数文档提示该 Flash Preview 暂不支持 top_p、seed、thinking_budget、thinking_strategy，reasoning_effort 不支持调整，默认 high；Light-DT 的 effort 不同，不能照搬其他 Provider 的 xhigh。接口状态、Token 用量、错误码、敏感数据策略都应逐项记录；Java 可用 Spring WebClient 以原生 JSON 请求接入，并由自定义 DTO/JSON Schema 校验返回结构。

百度千帆官方活动页列明 Flash Preview 限时五折至 2026-11-30 23:59:59：北京时间高峰 08:00–22:00 输入 1 元/百万 Token、输出 4 元/百万；低谷 22:00–08:00 输入 0.5 元/百万、输出 2 元/百万；缓存命中另计，活动到期自动恢复原价。Light-DT 标价输入 8 元/百万、输出 28 元/百万（不应等同于 Flash 活动价）。价格仅为这张官方产品页对应的活动与计费口径，未核实区域结算与专属合同，不能直接横向换算成美元后宣称“最便宜”。

验收步骤：（1）检查实名认证、地区、授权与预算上限；（2）先非思考普通文本和 JSON 输出；（3）中文代码仓库修复 10 题、长文档 10 题；（4）故意传不支持的参数，验证 400 和错误处理；（5）若视频模型可用，创建任务后通过 ID 轮询，禁止超时重复创建；（6）记录单次费用、Usage、P95、真实上下文限制和日志脱敏。验收： 回答与代码可验证、流式/非流式正常、超时无重复副作用、数据合规且有完整失败回滚策略。

⑦ 优先级和推荐动作。 必看（历史补录），建议阅读并在千帆测试账号做小规模 PoC；Preview 不宜直接替换生产主模型。权重发布需 11 月 25 日后根据官方实际开放情况再核实下载链接、许可证、商业限制与部署硬件，当前不宣称已开源。
