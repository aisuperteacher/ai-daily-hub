3.2 Extension render() 返回 readonly string[] —— Breaking

1.6.0 · 北京时间 2026-11-20 19:35官方来源

变化内容：Extension Components 的 render() 返回 readonly string[]；Container 在子节点未变时复用缓存数组。不得原地修改 super.render() 或内嵌组件返回数组，需复制后变更。

技术意义：组件渲染结果变成不可变数据契约，原地改动共享数组会污染缓存并导致不稳定显示。

受影响场景与行动

场景严重度方向明确行动Breaking-risk
TypeScript Extensions、自定义 TUI 组件HighBreaking + 渲染性能利好Change code / Test before upgradingHigh
仅使用兼容 Extensions 的普通 CLILow–Medium中性No action / Smoke testLow

TypeScript Extensions、自定义 TUI 组件 · 验证方法：迁移为 const lines = [...super.render(width)]; lines.push('Additional status'); return lines; 并做类型检查、宽度/重复渲染/嵌套组件测试。

仅使用兼容 Extensions 的普通 CLI · 验证方法：无需修改代码但可做扩展加载冒烟。

谁可以忽略：不开发自定义 Extension Components 的用户。

3.3 find Path Pattern 改为相对于搜索目录

1.6.0 · 北京时间 2026-11-20 19:35官方来源

变化内容：find 的 src/*.ts 只命中搜索根下 src/a.ts，不再命中 pkg/src/a.ts；跨层查找用 **/src/*.ts；没有 / 的文件名模式仍跨层匹配。

技术意义：Glob 搜索结果的减少不一定说明文件被删除，而可能是搜索语义改变。

简单文件名查询 · 验证方法：不含 / 的基本模式仍可跨目录。

06 · Windows PowerShell 5.1 / 7：只读检查

以下命令不安装或修改软件，npm Registry 查询需要网络。不要将任何可能包含服务器名称或环境变量内容的终端输出直接发到公开渠道。

# 1. Stable与预发布标签（只读）
npm view @openai/codex dist-tags --json
npm view @earendil-works/pi-coding-agent dist-tags --json
npm view @anthropic-ai/claude-code dist-tags --json
npm view @opencode/cli dist-tags --json
npm view @google/gemini-cli dist-tags --json

# 2. 本地真正执行的版本与路径
Get-Command codex,pi,claude,opencode,gemini -All -ErrorAction SilentlyContinue
codex --version
pi --version
claude --version
opencode --version
gemini --version

# 3. npm Global包与Runtime
npm ls -g --depth=0
node --version
npm --version

# 4. 仅查看Remote Exec帮助，不启动任务
codex exec --help

# 5. 只查询Qwen Token Plan变量是否设置，永不输出凭据内容
@(
 'QWEN_TOKEN_PLAN_TEAM_API_KEY',
 'QWEN_TOKEN_PLAN_TEAM_CN_API_KEY',
 'QWEN_TOKEN_PLAN_INDIVIDUAL_API_KEY',
 'QWEN_TOKEN_PLAN_INDIVIDUAL_CN_API_KEY'
) | ForEach-Object {
  [pscustomobject]@{
    Name = $_
    Set = [bool][Environment]::GetEnvironmentVariable($_)
  }
}
