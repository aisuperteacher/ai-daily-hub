MCP OAuth 跨 Host 重定向凭据泄露修复

2.1.321｜2026-11-09 19:22 UTC／北京时间 11-10 03:22官方发布来源

变化内容：修复 MCP OAuth 请求遇到跨 Host 重定向时，Refresh Token 等敏感凭据可能被发送到另一个 Host 的问题。
