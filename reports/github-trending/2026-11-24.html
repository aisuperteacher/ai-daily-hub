三、今日 Top 3 与选择理由

01

spring-projects/spring-ai

11 月 20 日正式版 2.1.0 带来现代 MCP 客户端、Session Recall 和多项连接与会话修复。对企业 AI 架构的落地影响高于单纯的 Star 热度。优先做 Boot 兼容、MCP、会话并发和回归测试。

02

Tracer-Cloud/opensre

CI 失败后人工排查通常占用大量时间。OpenSRE 将日志、失败作业和代码变更串成诊断证据，对 Java Maven 和企业 CI 有直接实践价值；但 Public Alpha 不适宜无审查地自动修改生产代码。

03

HKUDS/CLI-Anything

把软件能力做成 Agent 可测试的 CLI，比让 Agent 不断点击 GUI 更容易自动化与审计。最值得验证 Windows 工具接口、命令权限、错误码和调用幂等。

四、本期五项技术趋势和工程判断

趋势 1：企业 AI 框架转向 MCP+会话的稳定工程能力。Spring AI 2.1.0 的正式发布让现代 MCP 连接、Session Recall 和工具调用的兼容性成为可检验的落地问题；升级仍需要完整回归。

趋势 2：Agent 从写代码延伸到排查 CI。OpenSRE 的出现意味着 Agent 交付不应停在 PR 创建，故障日志、测试结果、修复 Diff 和人工批准同样重要。

趋势 3：Skills 从积累数量走向治理和可用性。Superpowers、Cursor Plugins、Stitch Skills 与 diagram-design 体现可复用能力增加；权限审查、跨客户端兼容和真实任务成功率比安装量更重要。

趋势 4：公开信息采集应绑定可追溯证据。Firecrawl 和 last30days-skill 可加速研究，但需要时间戳、原始来源、去重、条款合规和事实核验。

趋势 5：传统基础设施依然是 AI 应用的底座。NGINX、Argo CD、OpenJDK、OpenVINO 分别负责网络、交付、运行平台和推理，成熟度与安全升级比短期 Star 更重要。
