Part 04 / Architecture Signals

四、六项技术趋势与工程判断

01

AI 安全向多源证据整合发展

Codex Security 将独立审查、外部扫描器和明确的范围报告结合。企业应记录检测方法、源码位置、确认状态、修复结果与人工审核。

02

Windows Coding Agent 需要重视执行环境

Kimi Code 的 npx MCP、长路径和上下文恢复问题显示：很多日常失败发生在 CLI/协议/文件系统边界，而不只是模型推理能力。

03

确定性重构与 Agent 规划互补

shadcn/improve 可协助决策改什么，OpenRewrite 对可规则化改造输出可复现 Diff，再用 CI 和人类审查完成验收。

04

前端 Agent 从旧知识转向按需指南

Modern Web Guidance 提供最新浏览器模式，Astryx 提供组件实现，Agent Browser 验证交互结果，形成指导、实施、验收的闭环。

05

Java Agent 应把框架与业务职责分开

Spring AI 管理模型、数据和 MCP；AgentScope 管理运行状态；Floci 验证云依赖；领域服务继续负责授权、事务、幂等及补偿。

06

生产 Agent 需要多层约束和观测

HA-MCP 展示真实设备 Tool 的影响，Cilium 提供网络隔离，Prometheus 提供可测量运行指标。应叠加最小权限、审批、审计与故障恢复。
