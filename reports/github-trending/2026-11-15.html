五、六项技术趋势与架构取舍

1. 多 Agent 从角色数量转向交付保证

LoopForge SOP、OpenBot 审批与安全审查工具强调工作流证据、脚本测试、重试与人工验收，而不是只增加角色数。

2. AWS 本地测试有新的官方选择

AWS Emulator、Floci 和真实 AWS 承担不同测试层次；云权限、服务错误和异步行为必须做交叉验证。

3. Agent 共享记忆迈入数据库治理

Omnigraph 以分支、Schema、服务端策略规范知识写入；WeKnora 更侧重文档检索和知识应用，二者不必全部引入小型产品。

4. Windows AI Coding 依赖链复杂化

CC Switch 负责供应商路由，LoopForge 负责交付 SOP，Kiri 负责运行环境，必须同时检查 WSL、代理、端口、凭据与故障恢复。

5. 概率模型和确定性业务逻辑分层

Spring AI 管模型与 Tool，OpenRewrite 管确定性代码迁移，Iceberg 管分析数据；业务权限、事务及幂等仍要在可靠领域服务中实现。

6. 前端质量需真实验证

Modern Web Guidance 能向 Agent 提供现代 Web 和兼容建议，不能替代手机 Chrome、键盘、触控、屏幕阅读器和性能测试。
