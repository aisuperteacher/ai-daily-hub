四、今日六项技术趋势与取舍

1. 可复现比炫技重要：Agent Browser Saved Flows、工程 Skills 和 OpenRewrite Recipe 分别治理真实网页行为、开发流程与源代码改动。建议用测试成功率、返工和回滚时间衡量，而非同时运行多少 Agent。

2. MCP 正连接真实物理设备：HA-MCP 将读实体与设备写操作带入同一工具生态。设备控制必须做最小权限、独立测试环境、关键动作人工确认和凭据隔离。

3. 前端两条技术路线并行：Astryx 主打 React 组件和无障碍，Topcoat 强调 Rust SSR 与类型安全。不要仅凭热度替换已有栈，关键是兼容、性能与迁移成本。

4. 上下文成本不能牺牲正确性：billion-context 的作者自报节约需独立复现；压缩遗漏、隐私、缓存命中与需求召回要一起测量，不能混淆累计 Token 和单次窗口。

5. Java AI 架构必须分层：Spring AI 负责模型/MCP 集成，AgentScope 负责运行时；Floci 负责云 API 回归，Prometheus 负责观测，业务授权、事务和幂等仍属于领域服务。

6. 热度不是产品可靠性：Sure 是非 AI 应用的现象级候选；用户数据、许可证、备份和社区维护比星标更重要。
