  1. 1. 企业代码审查形成“规则管道 + LLM 审查 + 可复核报告”闭环：Alibaba OCR 和 Codex Security 分别处理质量与安全，不能互相替代；都需要测试、人工批准和可审计证据。

  3. 3. Java AI 应用的执行层和业务层仍需分离：Spring AI 用于模型/MCP，AgentScope 管理运行会话，领域微服务管理权限、事务与幂等，OpenRewrite 负责确定性迁移。
  4. 4. Windows 上的 Agent 协作正强调计划与审批：Plannotator 的本地 Review 和 Qwen Code 的后台任务可见性有实际价值，但 Hooks、云端连接和权限边界需要独立检查。
