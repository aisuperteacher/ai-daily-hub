四、五项技术趋势与工程判断

趋势 1｜Agent 工程化：从自主执行到可审计交付：LoopForge 用 SOP 和人工关卡协调执行；Plannotator 审阅计划与代码；Alibaba Open Code Review 以规则和模型检查 PR。组合比盲目提高自主度更重要。

趋势 2｜Skills 成为可测试、可治理的工程资产：Superpowers、Cursor Plugins、Stitch Skills、Cloudflare Security Audit Skill 表明 Skills 包含权限、工作流、质量标准及评测方法。安装数量并不是效果指标。

趋势 3｜AI 应用从聊天走向可编辑工作台：Univer 提供内容模型与可编辑数据；AG-UI 提供运行状态、工具事件和人工审批。两者可以实现用户可检查、可修改的 AI 产品。

趋势 4｜自托管工具更易用，但不能忽略权限：Arcane 简化 Docker 管理，却可能接触 Docker Socket 和高权限操作。权限、备份和升级治理必须优先于界面易用性。

趋势 5｜企业 Java AI 需要保持分层治理：Spring AI 处理模型与业务集成，AgentScope Java 处理长任务运行时，OpenRewrite 处理确定性源码迁移；业务事务与幂等应留在领域层。
