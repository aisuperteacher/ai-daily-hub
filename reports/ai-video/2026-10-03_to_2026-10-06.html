10/03

Runway Dev 上线 Grok Imagine Video 1.5 Lite

核心变化 1–15 秒，480p/720p/1080p；Runway Dev 计费 2/3/14 credits/秒，I2V 起始帧另加 1 credit。Lite 不支持 image/audio references，完整版 1.5 才适合 reference-heavy 镜头。

短剧价值 适合作为 Preview/Candidate Provider：低成本批量生成多个 take，再把 hero shot 路由到更强模型。

可用性 / 限制 已上线 Runway Dev。1080p 实际由 720p 生成后上采样，不能等同原生 1080p。

测试建议：★★★★★

10/06

ElevenAgents Architect：Agent 生产系统开始自我诊断、自我提出修改，并先跑模拟再让人批准

核心变化 ElevenLabs 10/6 发布 Architect。它可以分析 transcript、测试失败、升级率等信号，提出配置变更，自动写 simulation，所有改动先落到 versioned draft，需人批准后才上线。

短剧价值 这个模式非常适合短剧 Production Agent：分析失败 Shot/QC → 提出 Router/Prompt/Repair 规则变更 → 在测试集模拟 → 人工批准。

可用性 / 限制 当前 Alpha，主要面向 ElevenAgents，而不是影视专用产品；价值在“自改配置 + 模拟 + 版本化审批”的控制面设计。

测试建议：★★★★★（架构级）

补档期间的共同结论

1. Preview 与 Final Render 开始明显分层：Lite / Draft / Fast 模型适合批量候选，高价模型留给 Hero Shot。

2. Model Registry 需要新增 license_region、reference_capability、native_audio、expected_attempts。

3. Creative Flow 正在从 UI 变成 API / Template / MCP / Agent capability。

4. 自动化系统应该像 ElevenAgents Architect 一样：从失败数据提出改动 → 先模拟 → 生成 versioned draft → 人批准后上线。

今日补档小练习：20 分钟做一个 Preview→Final 两级 Router

选 3 类 Shot：建立镜头、角色对白、动作镜头。每类各指定一个低成本 Preview Provider 和一个高质量 Final Provider。定义晋级条件：Identity、Motion、Composition、Audio、Cost。Preview 只负责结构通过，Final 才负责成片质量。最后计算“直接全用 Final”与“两级 Router”的预期成本差。
